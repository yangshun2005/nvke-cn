# 背压

Collector 流水线使用同步处理器，并在导出器队列中批量处理数据。设置 `block_on_overflow: true` 后，队列满时传入调用会等待可用容量，从而让下游拥塞减缓数据摄入。内存限制器可在内存压力下拒绝数据，因此接收器和上游发送方必须重试可重试的失败。Filelog 接收器会重试这些失败直至恢复，并丢弃标记为永久性的错误。

每个 Collector 通过独立的 SDK 缓冲，将自身遥测数据导出到其[自遥测边车](self-telemetry.md)。日志和追踪使用有界异步队列，指标使用周期性读取器。边车拥有自己的有界队列，队列满时不会阻塞。这样可避免监控拥塞阻塞数据采集。

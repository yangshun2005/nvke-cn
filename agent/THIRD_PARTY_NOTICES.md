# 第三方声明

本项目链接了下列 Go 模块。此处完整转载其许可证，以确保从本仓库构建的二进制文件和容器镜像随附这些许可证所要求的署名。

## 范围

基于模块 `github.com/dsx-ai-factory/nvke/agent` 中 `./cmd/...` 的导入闭包生成，适用于 linux/amd64 和 linux/arm64。

索引链接标识的是固定版本的 Go 模块，与源码 URL 的发现方式无关。

Go 标准库已排除，属于本模块的包也已排除。仅用于测试的依赖和构建时依赖若无法从发布的命令到达，则不予列出，因为它们不会被分发。
